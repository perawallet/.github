## Pera Wallet

The open source, self-custody wallet for Algorand, on iOS, Android and in your browser.

[Website](https://perawallet.app) · [Docs](https://docs.perawallet.app) · [Support](https://support.perawallet.app) · [Blog](https://blog.perawallet.app) · [X](https://x.com/PeraAlgoWallet) · [Discord](https://discord.gg/gR2UdkCTXQ)

### Start here

| Repo | What it is |
|---|---|
| [pera-react-native](https://github.com/perawallet/pera-react-native) | The Pera Wallet app for iOS, Android and the browser extension |
| [connect](https://github.com/perawallet/connect) | `@perawallet/connect`, for connecting your dApp to Pera |
| [use-wallet-pera](https://github.com/perawallet/use-wallet-pera) | Pera adapter for TxnLab's use-wallet |
| [pera-walletconnect-ts](https://github.com/perawallet/pera-walletconnect-ts) | `@perawallet/walletconnect`, our WalletConnect v1 library |
| [pera-demo-dapp](https://github.com/perawallet/pera-demo-dapp) | Example dApp to try integrations ([live demo](https://perawallet.github.io/pera-demo-dapp/)) |

### Building a dApp?
Start with the [Pera Connect docs](https://docs.perawallet.app/references/pera-connect) and try your integration in the [demo dApp](https://perawallet.github.io/pera-demo-dapp/).

### Need help with your wallet?
Head to [support.perawallet.app](https://support.perawallet.app). Please don't post wallet or account problems as GitHub issues, and **never share your recovery phrase with anyone**, including people claiming to be Pera.

### Found a security issue?
Email **security@perawallet.app** and see our [security policy](https://github.com/perawallet/.github/blob/main/SECURITY.md).
