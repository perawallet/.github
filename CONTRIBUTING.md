# Contributing to Pera

Thanks for helping out! This is the default guide for Pera repos. If a repo has its own `CONTRIBUTING.md`, follow that one instead.

## Before you start
- **Security issues:** don't open an issue or PR. Follow the [security policy](https://github.com/perawallet/.github/blob/main/SECURITY.md).
- **Wallet or account problems:** go to [support.perawallet.app](https://support.perawallet.app).
- **Bigger changes:** open an issue first so we can agree on the approach before you put time in.

## Making a change
1. Fork the repo and create a branch from the default branch.
2. Keep the change focused. Add or update tests where it makes sense.
3. Make sure the repo's lint and tests pass.
4. Open a PR and fill in the template.

## Contributor License Agreement
Before we can merge your first contribution, you need to agree to our [Contributor License Agreement](https://github.com/perawallet/.github/blob/main/CLA.md). You confirm this with the CLA checkbox in the PR template.

## Never commit
Seed phrases, private keys, API keys, tokens, passwords or `.env` files, including test ones that touch real funds or services. If you commit one by accident, tell us right away. Deleting the commit isn't enough; the secret has to be rotated.
